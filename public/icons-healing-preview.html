使用方式

这套图标与主图标集同源同风格，既可以单独使用，也能和 css/icons-custom.svg 一起加载。

<!-- 1) 在页面底部加载精灵（可与主图标集并存） -->
<script src="js/svg-loader.js" data-svg-sprite="css/icons-healing.svg"></script>

<!-- 2) 在页面任意位置使用 -->
<svg class="icon icon--md"><use href="#icon-calm"></use></svg>

<!-- 3) 颜色继承父级 color，尺寸由 CSS 决定 -->
<style>
  .icon     { width: 24px; height: 24px; }
  .icon--md { width: 20px; height: 20px; }
  .icon--lg { width: 32px; height: 32px; }
</style>
