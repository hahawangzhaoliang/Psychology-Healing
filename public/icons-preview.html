📖 使用方式

方式一：HTML 内联（推荐）
<svg class="icon icon--lg"> <use href="#icon-heart"></use> </svg>
方式二：搭配 icons-custom.css 语义色
<svg class="icon icon--lg icon--warm"> <use href="#icon-heart"></use> </svg>
方式三：纯 CSS 控制颜色（自动继承）
<style> .my-icon { color: #f4a261; } </style> <span class="my-icon"> <svg class="icon"> <use href="#icon-leaf"></use> </svg> </span>
⚡ 点击任意卡片可复制图标 ID
